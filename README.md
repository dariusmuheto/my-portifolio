# Darius Muheto — Portfolio

A responsive personal portfolio built with **React + TypeScript**, **Tailwind CSS v4**, and **Material UI**.

## Requirements
- Node.js 20.19+ (recommended) or a current supported LTS release
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

## Customize before publishing

1. In `src/App.tsx`, update the email address (`hello@dariusmuheto.dev`) to your preferred public contact address.
2. Replace the GitHub and LinkedIn placeholder profile links with your real profile URLs.
3. Review the selected project summaries and publish only details you are comfortable sharing publicly.
4. Add project links or case-study pages when available.
5. Update the page title and meta description in `index.html` if needed.

## Stack
- React and TypeScript
- Vite
- Tailwind CSS v4 (via PostCSS)
- Material UI components and theme
- Lucide icons

The portfolio is intentionally self-contained and uses CSS-built artwork, so no image assets are required.
